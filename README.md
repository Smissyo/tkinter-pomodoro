# 🍅 Python Tkinter Pomodoro Timer

A clean, lightweight, and distraction-free Pomodoro timer desktop application built using Python and the standard `tkinter` library. 

---

## ✨ Features
* **Customizable Intervals:** Standard 25-minute work sessions paired with 5-minute short breaks (and longer breaks after 4 sessions).
* **Interactive Controls:** Start, Pause, and Reset functionality right at your fingertips.
* **Zero External Dependencies:** Built purely using Python's built-in `tkinter` library—no need to run `pip install` for heavy GUI frameworks.
* **Lightweight & Fast:** Starts instantly with a minimal system footprint.

---
